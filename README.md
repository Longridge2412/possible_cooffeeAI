# POSSIBLE COFFEE 焙煎サポーター

KALDI Fortis 専用の焙煎コンサルタントAI。POSSIBLE COFFEE（福島県西会津町の自家焙煎カフェ）の日々の焙煎で使うための道具です。

**公開URL：https://longridge2412.github.io/possible_cooffeeAI/**

現行バージョン：v9

---

## これは何か

焙煎の相談ができるチャットアプリです。2つのモードを持ちます。

- 🔥 **焙煎コンサルタントモード**（通常）— 焙煎前の設計、焙煎後の分析、カッピングからの逆算、Artisanの設定
- 📢 **広報モード** — Instagram・EC商品説明・note記事の文章作成（キーワードで自動切替、手動切替も可）

Artisanのデータファイル（.alog / JSON / CSV）やグラフ画像、PDFを添付して分析させることもできます。

## 使い方

1. サイトを開く
2. 初回のみ、[Anthropic Console](https://console.anthropic.com) で取得したAPIキー（`sk-ant-...`）を入力
3. 質問する

APIキーはブラウザのローカルストレージにのみ保存されます（送信先はAnthropic APIのみ）。

### ⚠️ 保存データについて

焙煎ログ・メモ・広報メモ・会話履歴は、**すべてブラウザの中だけ**に保存されます。

**iPhone / Safari は、7日以上サイトを開かないと保存データを自動削除します。** APIキーも焙煎ログも消えます。

対策として、📓記録パネル下部の **「💾 全データを書き出す」** で定期的にファイルへ保存してください。復元は「📥 バックアップを読み込む」から行えます。

### 動かないときは

**🔌 接続テスト** ボタンを押すと原因が特定できます。

| 表示 | 原因 | 対処 |
|---|---|---|
| ✅ 正常 | 問題なし | — |
| ❌ credit | クレジット残高ゼロ | Console → Plans & Billing で購入 |
| ❌ auth | APIキーが無効 | 「🔄 キーを変更」から入れ直す |
| ❌ model | モデルが使えない | 上部のモデル選択を切り替える |
| ❌ network | 通信できない | 電波・Wi-Fiを確認 |

**Claude.ai の月額プラン（Pro / Max）と、APIのクレジットは別会計です。** Claudeを契約していてもAPIは使えません。

## 構成

単一のHTMLファイルです。ビルド不要、依存ライブラリなし。

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体（全機能を含む） |

`index.html` を差し替えて push すれば、1分ほどで公開サイトに反映されます。

### 使用モデル

画面上部から3段階を選択できます。既定は「バランス」です。

| 表示 | モデル | 用途 |
|---|---|---|
| ⚖️ バランス | `claude-sonnet-5` | 通常はこれ |
| 🎯 高精度 | `claude-opus-5` | 難しいプロファイル分析 |
| ⚡ 高速・最安 | `claude-haiku-4-5` | 軽い質問 |

モデルが使えない場合は自動的に次の候補へ切り替わります（認証エラーや残高不足では切り替えません）。

## 開発者向け

### 知識データベース（システムプロンプト）

`index.html` 内の `SYS` 定数。**6部構成**になっています。

```
第1部 毎回必ず守るルール    言葉づかい・評価順序・禁止事項・検算
第2部 判断に使う数字        基準値の置き場所はここだけ
第3部 実機記録             実際に焼いたデータ（蓄積中）
第4部 背景知識             聞かれたら答える
第5部 記録コマンド
第6部 広報モード
```

**★編集時の最重要ルール★**

**判断に使う基準値は第2部にだけ置き、他の部では「2-2参照」のように参照すること。**

同じ数値が複数箇所にあると、片方だけ更新されて食い違いが生まれます。実際にv9では、ドロップ温度が3箇所に分散して `200〜215℃` と `198〜212℃` が併存していました。

編集後は、ブラウザのコンソールで以下を実行して検査してください。どちらも空配列になるはずです。

```javascript
// 基準値の重複チェック
const dup = n => { let c = 0, i = -1; while ((i = SYS.indexOf(n, i + 1)) >= 0) c++; return c };
['210〜213℃','185〜188℃','198〜203℃','203〜208℃','40〜45%','33〜38%','10分30秒〜13分','0.8kPa→0.6kPa','19℃/分']
  .filter(n => dup(n) > 1);

// 節番号の参照ズレチェック
const heads = [...new Set((SYS.match(/【\d-\d[^】]*】/g) || []).map(h => h.match(/\d-\d/)[0]))];
[...new Set(SYS.match(/\d-\d(?=[のを参照に、。（）])/g) || [])].filter(r => !heads.includes(r));
```

### ⚠️ 修正の効果を確認するとき

**必ず「🗒 新しい会話」を押してから試してください。**

会話履歴が残っていると、モデルが前回の自分の回答をほぼそのまま再生産します。これを忘れると、システムプロンプトを直しても効果がないように見えます。

### 設計上の注意点

- `effort` パラメータは Haiku 4.5 では非対応。送るとエラーになる
- `temperature` / `top_p` / `top_k` は Opus 5・Sonnet 5 では送ると 400 エラー
- Opus 5 は思考がデフォルトで有効。`max_tokens` は思考と本文の合計の上限
- システムプロンプトは2ブロック構造（固定部＋動的部）。固定部にプロンプトキャッシュを効かせているため、**固定部を1文字でも変えると全体のキャッシュが無効化される**。日付など動的な値を固定部に入れないこと
